## 📥 Шаг 1: Скачайте приложение

Выберите подходящую версию:

### Windows (рекомендуется)
1. Перейдите в [раздел Releases на GitHub](https://github.com/swirch/cluster-banned-manager/releases)
2. Скачайте `clusterbanned_0.1.6_x64-setup.exe`
3. Запустите установщик и следуйте инструкциям

### Android
1. Перейдите в [раздел Releases на GitHub](https://github.com/swirch/cluster-banned-manager/releases)
2. Скачайте `cluster-banned-manager.apk`
3. Разрешите установку из неизвестных источников в настройках
4. Установите приложение

---

## ⚙️ Шаг 2: Запустите с правами администратора

> [!IMPORTANT]
> **Для Windows:** Чтобы работала блокировка серверов, приложение **обязательно** нужно запускать от имени администратора.

**Как запустить:**
- ПКМ по ярлыку → "Запуск от имени администратора"
- Или настройте ярлык на постоянный запуск с правами администратора

---

## 🌍 Шаг 3: Выберите регион и сервер

1. В главном окне выберите ваш регион: **EU, RU, NA или ASIA**
2. Приложение автоматически покажет пинг до каждого сервера:
   - 🟢 **Зеленый:** <50ms — отлично
   - 🟡 **Желтый:** 50-100ms — нормально
   - 🔴 **Красный:** >100ms — плохо

---

## 🔒 Шаг 4: Настройте блокировку серверов

1. Отметьте серверы, которые хотите заблокировать
2. Нажмите **"Обновить блок"**
3. Приложение автоматически:
   - Добавит записи в файл `hosts`
   - Настроит правила брандмауэра Windows
   - Создаст резервную копию настроек

---

## 🎮 Шаг 5: Запустите игру

Нажмите кнопку **"Играть"** — игра запустится через Steam или Google Play с уже примененными настройками.

## ❗ Частые проблемы и их решение

| Проблема | Решение |
| :--- | :--- |
| **Не работает блокировка серверов** | **Причина:** Приложение запущено без прав администратора.<br>**Решение:** Закройте приложение и запустите его **от имени администратора**. |
| **Не определяются пинги серверов** | **Причина:** Брандмауэр или антивирус блокируют ICMP-запросы.<br>**Решение:** Добавьте приложение в исключения вашего брандмауэра или антивируса. |
| **Ошибка при обновлении hosts-файла** | **Причина:** Файл `hosts` защищен системой или используется другим приложением.<br>**Решение:** Убедитесь, что приложение запущено от имени администратора и закройте другие программы, которые могут использовать файл `hosts`. |
| **Приложение не запускается** | **Причина:** Отсутствует .NET Framework 4.8 или выше.<br>**Решение:** Скачайте и установите .NET Framework с официального сайта Microsoft. |
